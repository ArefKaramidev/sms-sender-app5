# برنامه ارسال پیامک (SMS Sender)

## توضیح
این پروژه یک اپلیکیشن اندروید ساده و شرکتی است:
1. کاربر شماره تلفن را وارد می‌کند (باید دقیقاً ۱۱ رقم باشد).
2. با زدن دکمه «تایید و ارسال»، شماره اعتبارسنجی می‌شود.
3. اگر شماره کمتر یا بیشتر از ۱۱ رقم بود، خطای مناسب نمایش داده می‌شود.
4. اگر معتبر بود، اپلیکیشن پیام‌رسان (SMS) پیش‌فرض گوشی با شماره و متن پیام از پیش نوشته‌شده باز می‌شود و کاربر فقط باید دکمه Send را در همان اپ بزند (طبق سیاست‌های امنیتی اندروید، اپلیکیشن‌های ثالث اجازه ارسال خودکار پیامک بدون تایید کاربر را ندارند مگر اپ پیش‌فرض پیامک خود گوشی باشد).

## متن پیام پیش‌فرض
متن پیام فعلی:
```
سلام
موقعیت مکانی شرکت سامان کشت نصف جهان را از لینک زیر دنبال کنید

https://arefkaramidev.github.io/Location-Sender/
```
این متن در فایل زیر قابل ویرایش است:
`app/src/main/res/values/strings.xml` → کلید `sms_body_template`

## نحوه ساخت (Build) فایل APK
من (Claude) در این محیط به اینترنت و Android SDK دسترسی ندارم، بنابراین نمی‌توانم مستقیماً فایل APK را کامپایل کنم؛ اما کل سورس‌کد آماده و کامل است. برای گرفتن APK:

1. Android Studio را نصب کنید (نسخه جدید، مثلاً Hedgehog یا بالاتر).
2. پوشه `SmsSenderApp` را با گزینه **Open** در Android Studio باز کنید.
3. صبر کنید تا Gradle Sync کامل شود (نیاز به اینترنت دارد تا وابستگی‌ها دانلود شوند).
4. از منو: `Build > Build Bundle(s)/APK(s) > Build APK(s)` را بزنید.
5. فایل APK نهایی در مسیر زیر ساخته می‌شود:
   `app/build/outputs/apk/debug/app-debug.apk`

برای گرفتن نسخه Release (برای انتشار رسمی) نیاز به امضای دیجیتال (Keystore) دارید که در Android Studio از مسیر `Build > Generate Signed Bundle / APK` قابل انجام است.
